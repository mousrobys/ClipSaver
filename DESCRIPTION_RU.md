# Краткое описание (русский)

**ClipSaver** — лёгкий локальный менеджер буфера обмена для Windows 11 с современным интерфейсом и поддержкой русского и английского языков.

Программа автоматически сохраняет скопированные текст, ссылки и изображения, позволяет просматривать историю, искать элементы, добавлять их в избранное и быстро возвращать в буфер обмена. ClipSaver работает в фоне, сворачивается в системный трей и открывается по горячей клавише `Ctrl + Shift + V`. По умолчанию включена тёмная тема, доступна светлая.

## Возможности

- Автоматическое сохранение текста, ссылок и изображений
- Работа в фоне и в системном трее
- Открытие по горячей клавише `Ctrl + Shift + V`
- Автозапуск с Windows (свёрнутым в трей)
- Поиск и фильтрация по типу
- Избранное
- Тёмная и светлая темы
- Автоопределение языка интерфейса (русский / английский)
- Ручной выбор языка в настройках
- Настройка лимита записей и срока хранения
- Полная очистка истории с сохранением избранного
- Локальное хранение в `%LOCALAPPDATA%\ClipSaver`
- Установщик с поддержкой русского и английского языков и автоматическим определением языка

## Установка

1. Откройте папку `Программа`.
2. Запустите **`ClipSaverSetup.exe`**.
3. Установщик автоматически определит язык Windows (русский или английский).
4. Следуйте мастеру установки. Установка выполняется для текущего пользователя:
   `%LOCALAPPDATA%\Programs\ClipSaver`
5. При желании включите автозапуск с Windows и создание ярлыка на рабочем столе.

Портативный вариант: `Программа\ClipSaver.exe` (не требует установленного .NET Runtime).

## Приватность

Все данные хранятся только на вашем компьютере. Нет аккаунтов, облака, сетевых запросов и телеметрии.
